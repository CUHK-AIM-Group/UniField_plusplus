# Execution validation

Validated on 2026-11-09 with the package versions in `tested_environment.json`, Python 3.11, CUDA 12.8 and NVIDIA RTX A6000 GPUs (48 GB each).

Two GPUs ran DistributedDataParallel training and a third GPU served the real Qwen3.5 planner through vLLM. Both stages used one real paired MRI volume, with an atlas registered to its low-field image. Each rank completed one optimizer step at batch size 1. Spatial preprocessing used 256 x 256 x 160 voxels and sampled 40 frames. The same pair was used for validation; this is an execution check, not an evaluation dataset.

| Stage | Training loss | Rank-0 peak allocated GPU memory | Result |
|---|---:|---:|---|
| Main training | 0.960332 | 28.37 GiB | Passed |
| TCDecoder LoRA fine-tuning | 0.102465 | 22.20 GiB | Passed |

Both runs checked finite losses and parameters, a change in trainable parameters, cross-rank parameter-sum agreement, checkpoint saving, and validation inference with finite PSNR, SSIM, NRMSE and LPIPS. Decoder training loaded the checkpoint generated by the main smoke run and verified that only its 74 TCDecoder LoRA tensors (16,586,121 parameters) were trainable. The resulting checkpoints and MRI data are not distributed.

The tested attention backend was `block_masked_pytorch_sdpa`. The optional native sparse-attention extension was not used. vLLM used eager execution, an 8192-token context, a 4096-token output budget and a 0.70 GPU memory utilization setting.

Additional checks passed:

- Four automated tests covering shared image/mask geometry and frame padding, rejection of an unbound atlas, masked-attention outputs and gradients against an independent reference, and decoder GPU/loop argument handling.
- Registration of a real low-field MRI using ANTsPy 0.6.3 and SciPy 1.15.3, with seven nonempty regional masks and matching native image geometry.
- Fresh download and SHA-256 verification of all four atlas/template resources.
- SHA-256 verification of all 34 initialization dependency files.
- Python source compilation, core training requirement resolution and editable-package metadata generation. The vLLM/Transformers metadata exception is documented in the installation instructions.

These checks establish short-run execution. They do not establish training convergence, anatomical registration accuracy across a dataset, or reproducibility of quantitative research results. Full-volume validation and long training runs were not tested here.
